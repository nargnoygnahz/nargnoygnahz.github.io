# 杨铭昊内卷网

一个关于现代生活平衡艺术的个人网站，探索在快节奏社会中如何找到属于自己的节奏和意义。

## 项目特色

### 🎨 设计理念
- **极简美学**：采用现代极简设计风格，注重内容呈现
- **响应式设计**：完美适配各种设备屏幕
- **深色主题**：营造专业、沉稳的视觉氛围
- **玻璃拟态**：使用玻璃卡片效果增强层次感

### 🚀 技术特性
- **交互式数据可视化**：内卷指数雷达图实时生成
- **动态背景效果**：P5.js粒子系统营造科技感
- **流畅动画**：Anime.js驱动的页面过渡和元素动画
- **智能表单**：根据联系目的动态调整表单字段

### 📱 页面结构
1. **首页** - 个人品牌展示 + 内卷思维可视化工具
2. **关于** - 个人故事 + 成长时间线 + 价值观阐述
3. **项目** - 作品展示画廊 + 筛选功能 + 详情模态框
4. **联系** - 智能联系表单 + 多种联系方式

## 技术栈

### 前端框架
- **Tailwind CSS** - 原子化CSS框架
- **Anime.js** - 轻量级动画库
- **ECharts.js** - 数据可视化图表库
- **P5.js** - 创意编程和图形渲染

### 设计系统
- **字体**：Playfair Display + Inter + Space Mono
- **色彩**：深蓝灰主色调 + 暖橙强调色
- **效果**：渐变、毛玻璃、悬停动画

## 核心功能

### 内卷思维可视化工具
- 5维度生活状态评估
- 实时雷达图生成
- 个性化建议系统
- 数据驱动的洞察分析

### 项目展示系统
- 9个精选项目案例
- 多维度筛选功能
- 详细项目信息模态框
- 技术栈和成果展示

### 智能联系系统
- 基于目的的智能表单
- 实时表单验证
- 多种联系方式整合
- FAQ常见问题解答

## 使用说明

### 本地运行
```bash
# 进入项目目录
cd /mnt/okcomputer/output/

# 启动本地服务器
python -m http.server 8000

# 访问网站
# http://localhost:8000
```
