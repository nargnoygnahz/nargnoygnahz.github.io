# 杨铭昊内卷网 - 交互设计

## 核心交互组件

### 1. 内卷思维可视化工具
- **位置**: 主页核心区域
- **功能**: 用户可以通过滑动条调整不同的生活维度（工作强度、学习投入、社交频率、休息时间）
- **交互**: 实时生成个性化的"内卷指数"雷达图和相应的建议
- **视觉**: 动态变化的彩色雷达图，配合文字建议

### 2. 个人成长时间线
- **位置**: 关于页面
- **功能**: 交互式时间轴展示个人成长历程
- **交互**: 点击时间节点显示详细信息，支持拖拽浏览
- **视觉**: 3D效果的时间轴，每个节点有独特的视觉标识

### 3. 项目作品展示画廊
- **位置**: 项目页面
- **功能**: 动态筛选和展示个人项目
- **交互**: 按类型、技术栈、时间筛选，悬停显示项目详情
- **视觉**: 卡片式布局，支持网格和列表视图切换

### 4. 智能联系表单
- **位置**: 联系页面
- **功能**: 智能识别联系目的，提供个性化回复模板
- **交互**: 根据输入内容动态调整表单选项和提示
- **视觉**: 渐进式表单设计，实时验证反馈

## 页面导航结构
- 首页：个人品牌展示 + 内卷思维工具
- 关于：个人故事 + 成长时间线
- 项目：作品展示 + 技能可视化
- 联系：智能表单 + 社交链接
